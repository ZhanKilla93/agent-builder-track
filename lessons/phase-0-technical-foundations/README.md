# Phase 0: Technical foundations

**Week 1.** Read a raw API request and response and say exactly what happened.

Everything later in this track is built from requests and responses. You don't need to write code from scratch, but you do need to read what goes over the wire, because that is where agents break.

- 0.5 [API keys and secrets](0-5-api-keys-and-secrets.md)
- 0.6 [Terminal, paths and config files](0-6-terminal-paths-and-config-files.md)

## Practice

1. Ask Claude Code to call any free public API (weather or currency rates) and print the full raw response: status, headers and body.
2. Label every part of it out loud or in notes.
3. Break it on purpose: use a wrong URL, then remove the key. Read each error and say what it tells you to do.
