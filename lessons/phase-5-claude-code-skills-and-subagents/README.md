# Phase 5: Claude Code, skills and subagents

**Weeks 8 to 9.** Configure Claude Code so it behaves predictably on a real project. CCAR-F Domain 3 (20%).

Claude Code is your main building tool. Configuring it well pays off far beyond the exam: the same ideas (always-on instructions, on-demand procedures, isolated workers) apply to every agent you build.

## Practice

1. Write a CLAUDE.md for your Phase 4 project: build commands, conventions, what not to touch.
2. Add one path rule (for test files), one skill and one read-only reviewer subagent.
3. Run the reviewer on a change and check it couldn't write files.
