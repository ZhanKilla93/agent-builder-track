# Phase 8: Capstone and exam readiness

**Weeks 12 to 13.** One real agent you can demo and explain end to end, plus exam readiness if you're eligible.

This is where the track turns into proof. In an interview, explaining why you built it this way counts for more than any certificate.

## Capstone checklist

- [ ] Orchestrator plus at least two subagents, with structured handoffs (Phase 4)
- [ ] Tools you designed, with clear descriptions and structured errors (Phase 2)
- [ ] At least one capability exposed through your own MCP server (Phase 3)
- [ ] A CLAUDE.md, one skill and one hook guarding a business rule (Phase 5)
- [ ] Structured output validated in code before anything is posted (Phase 6)
- [ ] Escalation to a person when unsure, plus a case facts block (Phase 7)
- [ ] A one-page write-up: what it does, the design choices, and what you'd change
- [ ] Demo it to the tutor and answer design questions

## Exam readiness

- [ ] Confirm with your manager whether your employer is in the Claude Partner Network
- [ ] Take the free CCAR-F diagnostic and note your weakest domains
- [ ] Re-run concept checks for every lesson in those domains
- [ ] If eligible: sit timed mock exams until you score above 800 twice in a row
- [ ] If eligible: book the real exam through the Partner Academy
